Kerno 2026.11.5 draws its value viewers in the theme's colours, reads a time with a zone in your own time
zone, and keeps the schema tree where it was when you refresh it.

If you run an earlier version, Kerno offers this update by itself: a dialog at launch, the proposal in the
status bar, or "Check for updates" in the About window. On Windows this is true from 2026.11.4 on; an
earlier Windows preview is updated by hand once.

## Install

| System | File |
|---|---|
| macOS, Apple Silicon | `Kerno-2026.11.5-macos-arm64.dmg` |
| Debian, Ubuntu (x86_64 / arm64) | `kerno_2026.11.5_amd64.deb` / `kerno_2026.11.5_arm64.deb` |
| Any Linux with glibc 2.31 or newer | `kerno-2026.11.5-linux-x86_64.tar.gz` / `kerno-2026.11.5-linux-aarch64.tar.gz` |
| AppImage | `Kerno-2026.11.5-x86_64.AppImage` / `Kerno-2026.11.5-aarch64.AppImage` |
| Windows, x86_64 (preview), installer | `Kerno-2026.11.5-windows-x86_64-setup.exe` |
| Windows, x86_64 (preview), no install | `kerno-2026.11.5-windows-x86_64.zip` |

`SHA256SUMS` lists the checksum of each file. The steps for each system are in the
[README](https://github.com/EvanPluchart/kerno#install).

On macOS the app is not notarized by Apple: the first time, open System Settings ▸ Privacy & Security and
click **Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Kerno.app`. On Windows the files
are not signed: SmartScreen may warn about an unknown publisher (**More info**, then **Run anyway**).

## New

- **The value viewers are drawn with the theme's colours.** A JSON value opened in the viewer, in the cell
  editor or in the value panel is laid out and coloured as the SQL editor colours its text: strings,
  numbers, `true` and `false`, and `null` as the grid draws NULL; blocks fold, and text can be selected. The
  hex view sets its offsets and its text gutter apart from the bytes. Light and dark, and a custom theme
  is followed.
- **A time with a zone, read in your own time zone.** Under a value that holds a time with a zone (a
  `timestamptz` or `timetz` cell, a text, the strings of a JSON document, an integer that is a Unix time), a
  switch "Times in my time zone" shows what each one is on this computer, with the offset of its own date
  (summer and winter time differ). The stored value and Copy never change. Off by default, remembered, and
  in the command palette.

## Better

- **Refresh keeps the tree where it was.** Refreshing a connection, a database, a schema or a folder, "Try
  again", and the refresh Kerno does itself after a script or a restore that ended well, read the tree
  again and bring back the nodes that were open and the selected row, instead of closing everything.
- **Importing connections when there is nothing to import**: the sentence that says so no longer runs out
  of the dialog's edge, and the notes a DBeaver import leaves to check are drawn as warnings.
- A long text (more than 64 kB) opens in the viewer without wrapping its lines, and the viewer says so:
  a document of several megabytes opens as fast as before and scrolls faster.

The full list, with the tests behind each item, is in
[docs/FEATURES.md](https://github.com/EvanPluchart/kerno/blob/main/docs/FEATURES.md).

## Known limits

- The macOS build is signed ad hoc, not notarized. The Windows files are not signed, and Windows is still a
  preview: nobody has used it by hand on a Windows desktop yet.
- The viewers colour JSON and the hex view; XML, HTML and PostgreSQL's arrays are shown as plain text.
- "Times in my time zone" uses the computer's zone; another zone cannot be chosen. A date and time without
  a zone is offered nothing, and that includes MySQL's `TIMESTAMP`, which Kerno shows without its zone. A
  `timetz` has no date: today's offset is used, and the line says so. In a document the first 20 times are
  listed.
- The limits of the earlier releases that this one does not change are in their notes:
