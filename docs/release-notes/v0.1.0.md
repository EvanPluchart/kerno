Kerno 0.1.0 is the first release: a native database client for macOS and Linux, for PostgreSQL, MySQL and
MariaDB.

## Install

| System | File |
|---|---|
| macOS, Apple Silicon | `Kerno-0.1.0-macos-arm64.dmg` |
| Debian, Ubuntu (x86_64 / arm64) | `kerno_0.1.0_amd64.deb` / `kerno_0.1.0_arm64.deb` |
| Any Linux with glibc 2.31 or newer | `kerno-0.1.0-linux-x86_64.tar.gz` / `kerno-0.1.0-linux-aarch64.tar.gz` |
| AppImage | `Kerno-0.1.0-x86_64.AppImage` / `Kerno-0.1.0-aarch64.AppImage` |

`SHA256SUMS` lists the checksum of each file. The steps for each system are in the
[README](https://github.com/EvanPluchart/kerno#install). There is no Windows build.

On macOS the app is not notarized by Apple: the first time, open System Settings ▸ Privacy & Security and
click **Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Kerno.app`.

## What is in it

- Connections with SSL/TLS, SSH tunnels through your own OpenSSH configuration (aliases, jump hosts, agents)
  or a built-in client, and passwords from the system keychain, a command, AWS RDS IAM, 1Password,
  `~/.pgpass` or `~/.my.cnf`.
- One sidebar tree for folders, connections, databases, schemas and objects, with a context menu on every
  row.
- A SQL editor with schema-aware completion, EXPLAIN as a plan tree, transactions per tab, history, saved
  queries, a formatter and an optional vim mode.
- A results grid that streams and stays smooth at a million rows, with find, sort, a value viewer, and
  export to CSV, JSON, SQL, Markdown and Excel.
- Table data editing with a review of the SQL and one-transaction apply; a form editor for tables.
- Environments with colours and rules; production asks twice before any write.
- An ER diagram, copying tables to another connection, running a script on several connections, backup and
  restore wizards, CSV import, an administration view.
- An AI assistant that is off until you turn it on, local model first, and shows exactly what it sends.

The full list, with the tests behind each item, is in
[docs/FEATURES.md](https://github.com/EvanPluchart/kerno/blob/main/docs/FEATURES.md); the measurements are in
[docs/BENCH.md](https://github.com/EvanPluchart/kerno/blob/main/docs/BENCH.md).

## Known limits

- The macOS build is signed ad hoc, not notarized. After an update the keychain may ask for your login
  password once.
- Memory at rest is about 150 MB with one connection and one query tab.
- The update check and the in-app installer were tested against a local stand-in, not yet against a published
  release.
- AWS RDS IAM and 1Password were tested with stand-ins for `aws` and `op`, and the AI assistant with a local
  endpoint.
- The Linux packages are checked by starting them in clean Ubuntu 20.04 and Debian 13 containers; no desktop
  session was part of that check.
