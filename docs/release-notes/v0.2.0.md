Kerno 0.2.0 adds split views, a value panel, old MySQL servers (5.1 to 5.7), a shortcuts page and saved AI
endpoints, and closes the gaps a full review of 0.1.0 found around transactions, cancellation and destructive
statements.

If you run 0.1.0, Kerno offers this update by itself: click the proposal in the status bar.

## Install

| System | File |
|---|---|
| macOS, Apple Silicon | `Kerno-0.2.0-macos-arm64.dmg` |
| Debian, Ubuntu (x86_64 / arm64) | `kerno_0.2.0_amd64.deb` / `kerno_0.2.0_arm64.deb` |
| Any Linux with glibc 2.31 or newer | `kerno-0.2.0-linux-x86_64.tar.gz` / `kerno-0.2.0-linux-aarch64.tar.gz` |
| AppImage | `Kerno-0.2.0-x86_64.AppImage` / `Kerno-0.2.0-aarch64.AppImage` |

`SHA256SUMS` lists the checksum of each file. The steps for each system are in the
[README](https://github.com/EvanPluchart/kerno#install). There is no Windows build.

On macOS the app is not notarized by Apple: the first time, open System Settings ▸ Privacy & Security and
click **Open Anyway**, or run `xattr -dr com.apple.quarantine /Applications/Kerno.app`.

## New

- **Split views.** Drag a tab to an edge of the tab area, or use Split Right (⌘⌥⇧L) and Split Down (⌘⌥⇧I):
  up to four groups side by side or stacked, each with its own tabs. The layout comes back after a restart.
- **A value panel beside the grid** (the "Value" button of a grid's footer, ⌃⌥V or F7). It follows the selected
  cell, shows JSON indented and coloured, and edits the value in place. On a foreign key it previews the row
  the key points to, with the columns you choose, and opens it.
- **MySQL 5.1, 5.5, 5.6 and 5.7.** Same MySQL engine in the dialog: Kerno reads the server's version and
  adapts. What an old release cannot do (a JSON query plan before 5.6.5, the list of locks on 5.1) is said in
  plain words instead of failing.
- **Settings ▸ Shortcuts.** Every command with its keys, a filter, recording a new key, a question when two
  commands would share one, reset. More default shortcuts, and "Theme: Switch Light and Dark" (⌘⇧D).
- **AI assistant: saved endpoints.** The page says what the assistant is for. Endpoints are found on this
  computer (Ollama, LM Studio and others), imported from an omp or pi configuration, or typed by hand; each
  keeps its model, picked from the list the server gives; a company certificate authority in the system store
  is trusted. A model's reasoning is left out of what is shown and inserted. Still off until you turn it on.

## Safer

- Quitting asks when a transaction is open or edits are pending. An open transaction shows on its tab, with
  its age; switching a tab to auto-commit asks what to do with it.
- A tab whose server session died says so before Commit, instead of committing nothing silently.
- Before `DROP … CASCADE`, `TRUNCATE … CASCADE` or a rename, Kerno lists what will be dropped, emptied or
  broken.
- A `DELETE` whose `WHERE` hides in a MySQL versioned comment, `PREPARE … AS DELETE` and `MERGE … THEN DELETE`
  are now treated as the writes they are.
- A `.sql` file never attaches itself to a staging or production connection without asking.
- Every long operation can be cancelled: applying edits, loading the tree, reading a structure behind a lock,
  the assistant's answer, opening a very large file.
- If Kerno cannot start (data from a newer version, a damaged store), it says why and offers a way out instead
  of closing; the store is copied before a migration.

## Better

- A query tab shows the database and schema its session is really in, after `USE` or `SET search_path`.
- Completion knows the columns of CTEs, subqueries and `LATERAL`.
- Routine bodies (`BEGIN ATOMIC`, MySQL `BEGIN … END`) run as one statement without `DELIMITER`.
- Every error shows the server's detail and hint.
- Settings can be searched, and each setting says what overrides it.
- The connection dialog: the URL example follows the engine, pasting a URL fills the form, and "Fill" takes
  the URL in the clipboard.
- Grids say when more rows are on the server and fetch them as you scroll; a table shows "Page 2 of 13". The
  light theme's grids have stripes, row lines and a header that stands apart.

The full list, with the tests behind each item, is in
[docs/FEATURES.md](https://github.com/EvanPluchart/kerno/blob/main/docs/FEATURES.md).

## Known limits

- The macOS build is signed ad hoc, not notarized. After an update the keychain may ask for your login
  password again; "Always Allow" stops it.
- Memory at rest is about 152 MB with one connection and one query tab, and each connection now holds one
  more server session, for the tree.
- This is the first update delivered through the in-app installer: until now it was tested against a local
  stand-in.
- Old MySQL servers: MariaDB before 10 was not tested; backing up a 5.1 server needs a 5.x `mysqldump` (the
  8.x one refuses it).
- The AI assistant was tested with local endpoints. Import and "Detect" merge into a saved endpoint with the
  same address without asking.
- In the dark theme a selected row's tint is faint: the selected cell's outline is what marks it.
