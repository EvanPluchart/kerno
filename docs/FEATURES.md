`partial: <what is missing>`, `todo: <plan file and part>` (not built yet). Test names are functions; the file is
given once per group, and a name followed by (PG, My, Ma) runs on those servers. Screenshot: files of
`docs/screenshots/`; `no screenshot` where there is none. Each item of CLAUDE.md §4 has at least one current

`no screenshot`. Committed code, HEAD `b34bd15`, 2026-11-14. Every
test name was checked to exist by searching the code; the suite was not run for this document.

The current captures are the 172 files of `docs/screenshots/final/` (`<screen>-<light|dark>.png`), taken on the
final code in the light and the dark theme; a row cites the light one with "(and -dark)". The other captures
(`docs/screenshots/*.png`, `m10-*.png`, `m10-p9-*.png`) were taken earlier in milestone 10 and show the feature
with the previous sidebar or without the main toolbar; a row cites one only where no `final/` capture shows it.

CLAUDE.md §4 B, whose item 1 is the clicks (labelled "B1 Clicks" below): CLAUDE.md B2 = B1 here, B3 = B2, B4 = B3.
