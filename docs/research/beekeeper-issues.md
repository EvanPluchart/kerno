# Beekeeper Studio issues: what users want, and where Kerno stands

Source: 827 issues of `beekeeper-studio/beekeeper-studio` (top 500 by +1, top 500 by comments, deduplicated),
`beekeeper-studio.json` in this folder. Demand = reactions + comments ("Σ"); `r`/`c` = reactions/comments of one
issue. The bodies and most-reacted comments of 46 issues were read with `gh issue view`. Kerno references are
paths in `/Users/e-pluchart/projects/perso/kerno` with line numbers (HEAD `97a05b8`, FEATURES.md dated
2026-11-13).

Scope filter (titles plus the bodies read): 678 issues kept. Dropped: 85 issues on other engines (Σ 888, the
largest single block: MongoDB #258 r80/c27, Oracle #20 r35/c26, ClickHouse #470/#1335, Snowflake #443, Redis
#80, SurrealDB #1373, Turso #1762, DuckDB #1500, BigQuery #83; SQLite is item 5 of `docs/ROADMAP.md:21`),
13 Windows-only (WSL2 #387/#364, PPK keys #49, Windows SSH agent #1444/#801, Windows ARM #2609, and #3202, whose
body points at Task Manager and `Beekeeper.exe`), 15 meta (contribution guides #287/#186, surveys), 36 too vague
to place. Classification is by keyword on titles plus manual fixes (script:
`../bkscripts/classify.py`, output `bk-classified.json`), so counts are close, not exact.

Category: **F** feature request, **UX** annoyance, **P** pain (performance, crashes, connection failures),
**R** Beekeeper regression (a bug of their code, nothing for Kerno to copy).

## Method notes

- Ranking by Σ favours themes made of many small bug reports (themes 1, 2, 9). Ranked by +1 reactions alone,
  the order of the top in-scope asks is: edit query results #2300 (29), whole-DB backup #778 (25), Run Current
  #1679 (25), double-click edit #39 (23), Flatpak #22 (20), reorder columns #1341 (19), diagrams #492 (18),
  settings screen #197 (18), open/save SQL #256 (17).
- #2968 (r35, "Update Electron to v35") is a maintenance chore counted in theme 1; without it theme 1 is Σ 438
  and still ranks in the top 3.
- Beekeeper's source code was not opened; only issues were read.
